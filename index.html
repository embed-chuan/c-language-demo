C 语言演进史

半个世纪的传奇历程

1972
Dennis Ritchie 创造 C
在贝尔实验室，C 语言诞生于 UNIX 操作系统开发项目，取代了 B 语言。
1978
K&R C 时代
《The C Programming Language》出版，成为 C 语言的非正式标准，被称为 K&R C。
1989
ANSI C (C89)
美国国家标准学会发布 C 语言第一个正式标准 ANSI X3.159-1989，奠定了现代 C 语言基础。
1999
C99 标准
引入 // 注释、变长数组、long long 类型、stdint.h 等重要特性，大幅提升了语言表现力。
2011
C11 标准
增加原子操作、多线程支持、泛型宏、匿名结构体等现代特性，使 C 更适应并发编程时代。
2024
C23 时代
最新标准引入 nullptr、constexpr、属性改进等，C 语言在持续进化中焕发新生。

指针 Pointer

直接操作内存地址，是 C 语言最强大也最危险的特性。掌握指针就掌握了 C 的灵魂。

🧩
结构体 Struct

自定义数据类型，将不同类型的数据组合在一起，是面向对象思想的萌芽。

📦
内存管理

malloc / free 手动管理内存，赋予开发者对资源的完全控制，也带来了更高的责任。

⚡
预处理器

#include、#define、条件编译，C 的预处理器提供了强大的元编程能力。
